# NEXUS

Для запуска готового сайта откройте `start.cmd` в корне проекта. [Перенос на другой ноутбук и структура проекта](../README.md). Команды ниже предназначены для разработки или отдельного размещения сервера.

Приложение использует Python-бэкенд. Добавьте статьи в PDF или ZIP, затем введите критерии или приложите отдельный PDF с заданием. Для PDF можно указать диапазон физических страниц. В исходном файле ВИНИТИ+ЮФУ страницы 3–6 относятся к солнечным элементам, а 7–10 — к RAG. Для PDF с критериями нужен читаемый текстовый слой.

Сервер модели выполняет задания по очереди. NEXUS показывает таблицы, замечания и страницы источников. В ZIP попадают CSV со строками данных и доступные привязки и замечания. История ссылок хранится в браузере, файлы заданий — на сервере.

## Сборка и запуск

Для сборки интерфейса используйте Node.js 24 с npm. Собранный сайт раздаёт Python-бэкенд. Машине с пакетом модели достаточно Python 3.10 или новее и каталога `frontend/dist`. Бэкенд подхватит `runtime/python.exe` рядом со скриптом модели.

```powershell
cd frontend
npm install
npm run build
cd ..
python .\backend\server.py --port 3000 --frontend-dir .\frontend\dist --jobs-dir .\backend\runs\nexus --runner 'C:\PDFModel\run_inference.py'
```

Сайт и API открываются по одному адресу `http://127.0.0.1:3000/`. Команда сохраняет задания в `backend/runs/nexus`.

Для разработки можно запустить `npm run dev` из `frontend`. Vite перенаправляет запросы к уже работающему API. Задайте его адрес в `NEXUS_BACKEND_URL` или используйте адрес по умолчанию `http://127.0.0.1:8081`. При отдельном запуске API разрешите адрес Vite через `--cors-origin http://127.0.0.1:3000`.

## Размещение для защиты

Запустите сборку на разрешённой машине, где может выполняться пакет модели. Текущий пакет предназначен для Windows x64. Размещайте сайт и Python API вместе, чтобы демонстрация могла работать с сервера без личного ноутбука.

Для доступа по домену направьте HTTPS-прокси на порт 3000, сохраняя заголовок `Host`. К команде запуска добавьте публичный адрес, например `--site-origin https://demo.example.org`. На сервер можно перенести `backend`, готовый каталог `frontend/dist` и распакованный пакет модели. Веса, PDF и результаты заданий передаются отдельно от исходников приложения.
