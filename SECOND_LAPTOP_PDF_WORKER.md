# Запуск обработки PDF на втором ноутбуке

На втором ноутбуке уже работает llama.cpp с моделью `nexus-qwen3-4b`. Оставьте его включённым. Обработчик ниже получает исходный PDF и критерии, читает страницы на втором ноутбуке, отправляет текст местной Qwen и возвращает результаты с цитатами. Он удаляет временную копию PDF после ответа.

1. Распакуйте `nexus-second-laptop.zip`. Переносимый Python для Windows x64 и библиотека чтения PDF входят в архив.
2. Узнайте IPv4 второго ноутбука командой `ipconfig`, затем запустите `./start-worker.cmd IP_ВТОРОГО_НОУТБУКА` из PowerShell. Тот же запуск вручную выглядит так.

   ```powershell
   $env:NEXUS_DUAL_WORKER_TOKEN = (Get-Content -LiteralPath '.\worker-token.txt' -Raw).Trim()
   .\runtime\python.exe -B -X utf8 -m article_analyzer.dual_worker --bind IP_ВТОРОГО_НОУТБУКА --port 8091 --qwen http://IP_ВТОРОГО_НОУТБУКА:8080/v1
   ```

3. На первом ноутбуке проверьте `Invoke-RestMethod 'http://IP_ВТОРОГО_НОУТБУКА:8091/health'`. Если порт закрыт брандмауэром, разрешите входящий TCP 8091 только от IPv4 первого ноутбука.
4. При настройке `"remote_worker": "auto"` NEXUS сам подключится к обработчику на порту 8091 при следующем задании. Токен уже сохранён на первом ноутбуке в `model_bundle/config/dual-worker.token`. Храните архив и токен внутри команды. По HTTP документы передаются по локальной сети без шифрования.

Если обработчик недоступен в режиме `auto`, второй проход идёт на Qwen по порту 8080. Первый ноутбук передаёт текст страниц, второй независимо проводит извлечение. В журнале такой запуск обозначен `page_text_to_qwen_api`. Полная передача PDF обозначена `pdf_to_second_worker`.
