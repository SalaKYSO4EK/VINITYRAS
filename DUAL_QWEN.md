# Извлечение PDF двумя экземплярами Qwen3‑4B

1. В текущей рабочей копии первый ноутбук запускается командой `start.cmd`. Скрипт проверяет доступность локального API. При необходимости запускает llama.cpp на `127.0.0.1:8086` и проверяет SHA‑256 локального GGUF. Для раздельного запуска используйте PowerShell `./tools/start-dual-qwen.ps1`, при необходимости с параметром `-LlamaServer`. Используется Qwen3‑4B Q4_K_M, файл занимает 2,50 ГБ.
2. На втором ноутбуке оставьте Qwen на порту 8080. В `model_bundle/config/qwen-api.json` на первом ноутбуке укажите её адрес с `/v1` и модель `nexus-qwen3-4b`. Для передачи исходных PDF запустите [обработчик PDF второго ноутбука](SECOND_LAPTOP_PDF_WORKER.md).
3. Откройте http://127.0.0.1:8087/. Файл `model_bundle/config/dual-qwen.json` включает два прохода. В новой копии проекта он создаётся запуском `./tools/start-dual-qwen.ps1`. Для повторного запуска используется существующая конфигурация.

Оба экземпляра независимо интерпретируют критерии. Для солнечного запроса используются имена столбцов исходного шаблона. Приложение проверяет привязку фактов к странице, сопоставляет поля и повторно отправляет спорные страницы обоим экземплярам. Нерешённые расхождения видны в предупреждениях задания. В архив попадают только CSV с данными.

Для просмотра отдельных результатов каждого прохода, повторной сверки и физических страниц используйте `backend/runs/local/<job_id>/output/reconciliation.json`. В папке задания также есть журнал выполнения, схема критериев и отчёт. Старые задания доступны по прежним ссылкам.

Для короткой проверки загрузите `P078.pdf` и запросите «Извлеки только название статьи». Для научной проверки на одном фрагменте задайте «Извлеки только средний и максимальный PCE для образца 4-Ni-NG/CE на физической странице 7 из Table 2. Укажи единицы и цитату». Запрос по нескольким показателям всей статьи займёт дольше. Время зависит от размера PDF, длины выдачи и производительности первого ноутбука.
