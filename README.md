# VINITYRAS

Локальный прототип извлечения данных из научных публикаций. Пользователь загружает PDF или ZIP с PDF и задаёт критерии. Сервер обрабатывает задания по очереди и выдаёт CSV, ссылки на страницы источников и ZIP с результатами.

## Запуск

Для встроенной страницы и API нужен Python 3.10 или новее.

```powershell
python .\backend\server.py
```

Страница открывается по адресу `http://127.0.0.1:8080/`. Для обработки PDF укажите путь к `run_inference.py` из распакованного пакета модели через `--runner`.
